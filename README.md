# Gig Player

A stage-ready progressive web app for local backing tracks.

Add audio files from a device, organize songs and speaking notes into playlists, reorder and rename setlist entries, and play one track at a time. Track files and playlist data are stored in the browser on the device; they are not uploaded to this site.

## Local development

Serve this folder from `localhost` or an HTTPS host to enable service workers, installable PWA behavior, and screen wake lock support.
